# natlab — P2P NAT 穿透端到端离散事件仿真

一个完全用 Go 编写、**不依赖真实网络**的连接建立仿真系统。终端、NAT 地址转换设备、
STUN 式探测服务器、信令服务器、TURN 式中继服务器以及网络链路全部由离散事件引擎建模，
用于评估"终端直连"系统在各种 NAT 组合下的连通率、建连耗时、中继成本，并与独立的理论
判定逐组合对照。

## 目录结构

```
internal/
  sim/         离散事件引擎：虚拟时钟、事件堆、报文、节点、链路延迟/抖动/丢包
  nat/         NAT 设备：三种映射 × 三种过滤 × 三种端口策略、超时、协议屏蔽、多层嵌套
  server/      探测服务器(双IP双端口)、信令服务器、中继服务器(地域/运营商/容量/负载)
  agent/       终端连接策略：
                 full.go     完整方案（候选收集/ICE 式打洞/端口预测/保活/中继/ICE 重启）
                 baseline.go 简单打洞基线（单 UDP 候选、无预测、盲选中继、无重协商）
                 discovery.go STUN 式行为探测与 NAT 类型/端口规律识别
  truth/       独立的分析判定（不依赖仿真），给出每个组合理论上能否直连
  scenario/    世界组装：NAT 原型、终端、链式多层 NAT、唯一地址规划、移动网络
  experiment/  全矩阵运行、聚合统计、热力图折叠、带时间线的单次追踪、移动性场景
  web/         内嵌仪表盘（go:embed 单页，无外部依赖）
cmd/natlab/    CLI：跑矩阵并输出 JSON，或 serve 启动面板
```

## 快速开始

```bash
# 1) 运行全矩阵（12 原型 × 12 原型 × 4 种子 × 2 策略），写入 webdata/
go run ./cmd/natlab -seeds 4 -duration 15

# 2) 启动仪表盘
go run ./cmd/natlab serve -addr :8080 -data webdata
# 浏览器打开 http://localhost:8080
```

## 仿真的 NAT 行为

| 维度 | 取值 |
|---|---|
| 映射类型 Mapping | EIM 端点无关 / ADM 按目的地址 / APDM 按目的地址+端口（对称） |
| 过滤类型 Filter  | EIF 端点无关 / ADF 地址相关 / APDF 地址+端口相关 |
| 端口策略 Port    | preserve 保留 / increment 递增（可预测）/ random 随机 |
| 其它 | 映射超时（含抖动）、UDP/TCP 协议屏蔽、多层 NAT 嵌套、hairpin |

内置 12 个原型：fullcone、restricted、portrestricted、symmetric(preserve/inc/rand)、
addr-dependent、short-timeout、两种双层嵌套、udp-blocked、tcp-blocked。

## 连接建立流程（完整方案）

1. **地址探测**：经双 IP/双端口探测服务器，5 步探测识别外部地址、映射类型、过滤类型，
   并采样外部端口序列识别端口规律（保留/递增/随机）。
2. **候选交换**：host / srflx / relay 候选经可靠信令交换，srflx 携带预测端口与对称标志。
3. **连通性检查**：按 ICE 优先级同时打洞；对递增对称 NAT 发出预测端口窗口探测；
   学习 peer-reflexive 候选；要求双向 ACK 确认才宣布直连。
4. **中继回退**：直连预算耗尽后，对全部中继实测 RTT，按
   `0.55·RTT + 0.20·地域 + 0.10·运营商 + 0.15·负载` 加权选优，并经信令协商双方共用中继。
5. **保活**：以短于最短 NAT 超时的间隔刷新映射。
6. **网络切换**：终端切换网络后触发 ICE restart，重新探测/交换/检查并恢复连接。

## 理论对照

`internal/truth` 用纯分析规则独立给出每个组合的判定（`direct-udp` / `direct-udp-predict`
/ `direct-tcp-simopen` / `relay-only`），实验运行器逐次比对仿真结果与该判定，
输出 `theory_match_rate`。

## 验收指标（4 种子默认配置下的代表性结果）

| 指标 | 完整方案 | 简单打洞基线 |
|---|---|---|
| 成功率 | **100.0%** | 91.7% |
| 直连率 | **82.6%** | 45.8% |
| 完全失败 | **0** | 48 / 576 |
| 中继流量占比 | **12.8%** | 37.1% |
| 中继探测 RTT | **16 ms**（就近选优） | 44 ms（盲选第一个） |
| 理论对照率 | **100.0%** | 53.5% |
| 端口预测命中 | 79 | 0 |

仪表盘三个标签页分别对应：**① NAT 组合结果矩阵热力图**、**② 单次连接探测时间线**
（含网络切换重协商）、**③ 中继负载与选择**，另有完整方案 vs 基线的并排对比页。
